# Code-A-Robot Simulator

A work-in-progress browser-based FTC robotics simulator and robot builder intended to extend
[codearobot.org](https://codearobot.org).

Project documentation lives in the Obsidian-compatible [`documentation`](./documentation/README.md)
directory. Start with the [documentation home](./documentation/README.md) or the
[project overview](./documentation/01%20-%20Project%20Overview.md).

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
